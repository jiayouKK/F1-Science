3. Accuracy, Consistency, Sensitivity

准确度、一致性、灵敏度
Accuracy 准确度
close to true value
结果接近真实答案
Consistency 一致性
close to each other
结果彼此接近，不一定准
Sensitivity 灵敏度
finer scale = more sensitive
刻度越密，测出的差异越小
Parallax error 视差
眼睛要跟刻度线打平视线（perpendicular），从上或从下看都会有视差
Zero error 零误差（巴刹电子秤还没放东西已经显示数字，就是这个）：
No zero error
没有零误差
Positive 正零误差
读数中要减掉
Negative 负零误差
读数中要加回
Actual reading = Reading − Zero error

4. Vernier Caliper & Screw Gauge 读数题必考

游标卡尺与千分尺

Vernier caliper 精确度 0.01 cm；Screw gauge 精确度 0.01 mm，测更小的物体更准确。

Vernier caliper 游标卡尺
Reading = Main scale + (对齐格数 × 0.01)
= 3.40 + 0.05 = 3.45 cm
Screw gauge 千分尺
Reading = Sleeve scale + (Thimble scale × 0.01)
= 5.5 + 0.28 = 5.78 mm
🎯 练习：读出上面这个游标卡尺的读数

5. Density 公式题

密度
Density = Mass ÷ Volume　（ρ = m/V）　unit: kg/m³ or g/cm³
同样是铁，形状改变了体积（不是密度）→ 船能浮
