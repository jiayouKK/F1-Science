2. Accuracy, Consistency, Sensitivity

准确度、一致性、灵敏度
Accuracy 准确度
close to the true value
结果接近真实答案
Consistency 一致性
close to each other
结果彼此接近，不一定准
Sensitivity 灵敏度
finer scale = more sensitive
刻度越密，能测出的差异越小
Zero error 零误差：仪器一开始没归零，磅秤还没站上去指针已经歪了
Parallax error 视差：眼睛没跟刻度打平视线，看时间时指针明明在12却看歪了

2b. Vernier Caliper & Screw Gauge 读数题必考

游标卡尺与千分尺

Vernier caliper 精确度 0.01 cm；Screw gauge 精确度 0.01 mm，比ruler更准。

Reading = Main scale + (Vernier scale coinciding line × 0.01)
= 3.40 + 0.05 = 3.45 cm
Zero error 零误差（卡尺合起来时指针没对准0）：
No zero error
没有零误差
Positive 正零误差
要在读数中减掉
Negative 负零误差
要在读数中加回
Actual reading = Reading − Zero error
🎯 练习：读出这个卡尺的读数
