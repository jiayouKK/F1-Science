3. Accuracy, Consistency, Sensitivity

准确度、一致性、灵敏度
Accuracy 准确度
close to true value
Consistency 一致性
close to each other
Sensitivity 灵敏度
finer scale = more sensitive
Parallax error 视差
Eyes must be perpendicular (level) to the reading — 眼睛要跟刻度打平视线
Zero error 零误差（秤上面没有东西但是有重量了）：
No zero error
Positive 正零误差
读数中要减掉
Negative 负零误差
读数中要加回
Actual reading = Reading − Zero error

5. Density

密度
